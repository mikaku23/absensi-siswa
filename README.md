# 📌 Website Absensi Siswa

Website ini bertujuan untuk mempermudah guru dalam mengabsen siswa di sekolah. Proyek ini dibangun menggunakan:

- **Framework:** Laravel 11
- **Database:** MySQL
- **Editor:** Visual Studio Code (VS Code)
